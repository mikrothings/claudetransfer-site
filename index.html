Claude Transfer

A small Windows command-line tool that moves and syncs your Claude Code session data between your own computers.

If you work on a desktop at home and a laptop on the road, Claude Transfer keeps your conversations, project memory and settings the same on both. It can also export everything to a file before you reinstall Windows and bring it back afterwards, rewriting project folder paths when they differ between machines.

Export and import

Move projects one by one to another computer, with a new disk, folder or user name for each.

Sync through your Drive

Run claude-transfer sync on one machine, then on the other. Nothing runs in the background.

No data loss

When both sides changed the same conversation, the tool asks you, and can keep both copies.

Backups

Keeps a local copy of anything it overwrites, and can take a full backup on request and upload it to your Drive.

How it uses Google Drive

Claude Transfer signs in with your Google account and asks only for the drive.file permission. That permission lets it see and change only the files it created itself, in a folder named claude-transfer in your Drive. It cannot see any of your other Drive files.

The tool runs only on your computer and talks directly to Google. There is no Claude Transfer server: your data and your sign-in never reach the developer. Details are in the privacy policy.

Who it is for

Claude Transfer is a personal tool built and used by Mikrothings. It is a standalone Windows executable and needs no other software installed.
