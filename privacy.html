Privacy Policy

Effective 9 November 2026

Claude Transfer ("the app") is a Windows command-line tool made by Mikrothings. It copies Claude Code session data between computers that belong to the same person. This policy explains what the app reads, where that data goes and how you can remove it.

Summary

  • The app runs only on your computer. There is no Claude Transfer server.
  • Your data goes only to your own Google Drive, and only when you run a sync or upload a backup.
  • The developer never receives your data, your Google account details or your sign-in.
  • The app does not use analytics, tracking, advertising or telemetry.

Data the app reads on your computer

To do its job, the app reads the files Claude Code keeps on your computer: conversation transcripts, prompt history, project memory files, settings and the session list of the Claude desktop app. These files can contain anything you typed into Claude Code or that Claude Code read for you, including source code and personal information. The app reads them only to copy them, and changes only file paths inside them so that they fit the other computer.

Google user data

The first time you sync (or run claude-transfer drive login), the app opens Google's sign-in page in your browser and asks for one permission: https://www.googleapis.com/auth/drive.file. With it the app can:

  • create a folder named claude-transfer in your Google Drive;
  • create, read, update and delete the files it put in that folder.

It cannot see, read or change any other file in your Google Drive. It does not access your Gmail, contacts, calendar or any other Google service, and it does not read your name, email address or profile.

How Google user data is used

Files in the claude-transfer folder are used only to keep your own computers in sync and to restore your own backups. They are never used for any other purpose, including advertising, profiling or training of machine learning models.

How Google user data is shared

It is not shared with anyone. The data moves only between your computer and your Google Drive, directly over Google's encrypted (HTTPS) API. Neither Mikrothings nor any third party receives it.

How Google user data is stored and protected

  • Your synced data is stored in your Google Drive under Google's own security and retention terms.
  • The sign-in token Google gives the app is stored only on your computer, in %LOCALAPPDATA%\claude-transfer\token.dat, encrypted with Windows Data Protection (DPAPI) so that only your Windows user account can read it. It is never uploaded anywhere.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

The app keeps the data in your Drive until you delete it. You can remove everything at any time:

  • Run claude-transfer drive logout to delete the sign-in token from your computer.
  • Revoke the app's access at myaccount.google.com/permissions.
  • Delete the claude-transfer folder from your Google Drive to remove all synced data and uploaded backups.
  • Delete the %LOCALAPPDATA%\claude-transfer folder and any local backup folder to remove the app's local files.

Because the developer never holds any of your data, there is nothing for the developer to delete on your behalf.

Children

The app is a developer tool and is not directed at children under 13.

Changes

If this policy changes, the new version will be posted on this page with a new effective date.
